# 🎾 Wintertennis Planner

Welkom bij de Wintertennis Planner!

Met deze applicatie kun je eenvoudig de volledige wintercompetitie bekijken. Je vindt hier jouw persoonlijke speelplanning, alle wedstrijden per speeldag en een analyse van de planning.

## Functionaliteiten

* 📅 Overzicht van alle speeldagen
* 🎾 Persoonlijk wedstrijdschema
* 📄 Planning exporteren naar PDF
* 📆 Eigen agenda downloaden als ICS-bestand
* 📊 Analyse van de planning en spreiding van wedstrijden

## Slimme planning

De planning wordt automatisch samengesteld waarbij zoveel mogelijk rekening wordt gehouden met:

* spelen tegen nieuwe tegenstanders;
* afwisseling van medespelers;
* indeling op hetzelfde niveau;
* mixed dubbels waar mogelijk;
* vaste teams die altijd samen blijven.

Hierdoor ontstaat gedurende het seizoen een zo eerlijk en gevarieerd mogelijke competitie.

## Privacy

Privacy vinden we belangrijk.

In deze openbare deelnemersomgeving zijn uitsluitend de gegevens opgenomen die nodig zijn om de planning te tonen. Er worden **geen telefoonnummers, e-mailadressen of andere contactgegevens** gepubliceerd.

Persoonlijke contactgegevens blijven uitsluitend beschikbaar in de afzonderlijke beheeromgeving en maken geen onderdeel uit van deze openbare website.

## Broncode

Deze applicatie is ontwikkeld als maatwerkproject en wordt gepubliceerd via GitHub Pages. Nieuwe planningen worden vanuit de beheeromgeving gegenereerd en vervolgens als nieuwe versie van deze website gepubliceerd.

Veel speelplezier en een sportief wintertennisseizoen!
